เข้าใจ Grid Code ก่อนเริ่มออกแบบ

4 เรื่องที่ช่วยป้องกันการเลือกอุปกรณ์ผิดและต้องแก้ BOQ ภายหลัง

01. kWp ≠ Export kWขนาดแผง PV (DC), กำลัง Inverter (AC) และกำลังส่งเข้าระบบที่ กฟภ. อนุญาต เป็นคนละค่า
02. ประเภทโครงการแยก IPU / IPS ผลิตใช้เอง กับ VSPP / SPP ที่ขายไฟฟ้าตามข้อตกลงก่อนเลือกแบบ Annex 7.1
03. PCC เป็นจุดชี้ขาดการเลือก LV / 22–33 kV / 115 kV ส่งผลต่อ Protection, CT/VT, PQM, SCADA และการศึกษาระบบ
04. ข้อกำหนดมีเงื่อนไขไม่ใช่ทุกโครงการต้องมี SCADA หรือ PQM เหมือนกัน ต้องดูประเภท/พิกัดรวม/ระดับแรงดัน

Solar Rooftop ผลิตใช้เอง

ROOFTOP • SELL / EXPORT

Solar Rooftop ขายหรือส่งไฟ

SOLAR FARM • SELF-CONSUMPTION

Solar Farm ผลิตใช้เอง

ถ้าเป็น IPU/IPS และเชื่อมระบบ กฟภ. ให้ตรวจ Zero Export, MV Protection, Load Flow/PQ และ O&M

SOLAR FARM • GENERATOR / EXPORT

Solar Farm เพื่อขายไฟ

ตรวจ VSPP/SPP, ระบบ 22/33/115 kV, Feeder Hosting, Relay, PQM, SCADA และการทดสอบตามแบบที่อนุมัติ
