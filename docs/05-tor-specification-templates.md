# 05 — ตัวอย่างข้อกำหนด TOR / Technical Specification

[← กลับหน้าหลัก](../README.md) · [← Checklist](04-site-inspection-checklist.md) · [ต่อไป: แหล่งอ้างอิง →](06-sources-and-maintenance.md)

> **หมายเหตุด้านการใช้งาน:** เนื้อหานี้เรียบเรียงจาก HTML และภาพสรุปที่แนบมา ไม่ใช่ประกาศหรือหนังสืออนุมัติอย่างเป็นทางการของ กฟภ. ก่อนนำตัวเลข/ข้อกำหนดไปใช้ใน TOR, BOQ, งานออกแบบ หรือยื่นเชื่อมต่อ ให้ตรวจเอกสาร กฟภ. ฉบับเต็มและหนังสืออนุมัติเฉพาะโครงการอีกครั้ง

> **ข้อจำกัด:** ข้อความต่อไปนี้ถอดจากร่าง TOR ใน HTML แนบ **ไม่ใช่ถ้อยคำจากประกาศ กฟภ. โดยตรง** ผู้จัดทำ TOR ต้องปรับตามประเภทโครงการ รายละเอียดงาน ข้อกำหนดสัญญา และหนังสืออนุมัติของ กฟภ. ก่อนใช้งานจริง

## 1. ขอบเขตการปฏิบัติตาม Grid Code

**ขอบเขตการใช้:** ทุกโครงการ  
**อ้างอิงในไฟล์ต้นฉบับ:** `C ข้อ 1.4, 2; S ข้อ 2; O ข้อ 2`

> ผู้รับจ้างต้องออกแบบ จัดหา ติดตั้ง ทดสอบ และจัดส่งเอกสารประกอบการเชื่อมต่อระบบผลิตไฟฟ้าพลังงานแสงอาทิตย์กับระบบโครงข่ายไฟฟ้าของการไฟฟ้าส่วนภูมิภาค (กฟภ.) ให้สอดคล้องกับข้อกำหนดเกี่ยวกับการเชื่อมต่อ การใช้บริการ และการปฏิบัติการระบบโครงข่ายไฟฟ้าของ กฟภ. ที่มีผลบังคับใช้กับโครงการ รวมถึงเงื่อนไขที่ กฟภ. อนุมัติเป็นลายลักษณ์อักษร ทั้งนี้ต้องระบุจุดเชื่อมต่อ (PCC) ระดับแรงดัน รูปแบบโครงการ และกำลังผลิต/กำลังส่งเข้าระบบที่ขออนุญาตให้ชัดเจน

## 2. การออกแบบระบบป้องกันและ Inverter

**ขอบเขตการใช้:** ระบบ Inverter  
**อ้างอิงในไฟล์ต้นฉบับ:** `C ข้อ 2.3, 2.9 และเอกสารแนบท้าย 7.1/7.4`

> ผู้รับจ้างต้องเลือกใช้ Inverter และออกแบบระบบป้องกัน ณ จุดเชื่อมต่อให้เป็นไปตามข้อกำหนด กฟภ. รวมถึง Anti-Islanding, Under/Over Voltage, Under/Over Frequency, Frequency Ride-Through, Power Factor Control และฟังก์ชันควบคุมกำลังไฟฟ้าที่เกี่ยวข้อง โดยต้องเสนอ Single Line Diagram, Protection Philosophy, Relay/Inverter Setting Sheet, เอกสารรับรองและแผนทดสอบให้ผู้ว่าจ้างตรวจสอบก่อนดำเนินการติดตั้งหรือจ่ายไฟเข้าระบบ

## 3. ระบบ Zero Export / Export Limiting

**ขอบเขตการใช้:** เลือกใช้ตามรูปแบบโครงการ  
**อ้างอิงในไฟล์ต้นฉบับ:** `C ข้อ 2.2.4, 3.3.1 และ Annex 7.1`

> สำหรับระบบประเภท IPU/IPS ผู้รับจ้างต้องจัดให้มีระบบควบคุมไม่ให้พลังงานไฟฟ้าไหลย้อนเข้าสู่ระบบโครงข่ายไฟฟ้าของ กฟภ. ณ จุดเชื่อมต่อ ตามแบบและเงื่อนไขที่ได้รับอนุมัติ โดยแสดงตำแหน่ง CT/Meter/Controller และผลทดสอบการจำกัดกำลังส่งออก ในกรณีระบบผลิตเพื่อขายไฟฟ้าหรือจ่ายไฟเข้าระบบ ให้กำหนด Export Limit ตามขนาดที่ กฟภ. อนุญาต และติดตั้งอุปกรณ์ EXL ตามเงื่อนไขที่เกี่ยวข้อง

## 4. PQM, Monitoring และ SCADA

**ขอบเขตการใช้:** ใช้เมื่อเข้าเงื่อนไข  
**อ้างอิงในไฟล์ต้นฉบับ:** `C ข้อ 2.4.4, 2.6, Annex 7.2–7.3`

> ผู้รับจ้างต้องตรวจสอบขนาดกำลังผลิตรวม ระดับแรงดัน และรูปแบบการเชื่อมต่อ เพื่อกำหนดความจำเป็นของ Power Quality Meter, Monitoring System และระบบควบคุม/สื่อสารระยะไกล โดยเสนอ Metering & Communication Architecture, Data Point List, Protocol, Power Supply, ตำแหน่งติดตั้ง และวิธีทดสอบ FAT/SAT ตามข้อกำหนด กฟภ. ที่ใช้บังคับ ทั้งนี้ต้องไม่สรุปว่าทุกโครงการมีหน้าที่ติดตั้ง SCADA เหมือนกันโดยไม่ตรวจรูปแบบการเชื่อมต่อ

## 5. ทดสอบก่อนเชื่อมต่อและส่งมอบ

**ขอบเขตการใช้:** ทุกโครงการ  
**อ้างอิงในไฟล์ต้นฉบับ:** `S ข้อ 3.1–3.3; O ข้อ 2.3–2.4; C Annex 7.4`

> ก่อนจ่ายไฟเชื่อมต่อระบบ ผู้รับจ้างต้องจัดส่ง As-built Drawings, Test Procedures, Inverter/Relay Settings, Protection & Interlock Test Reports, Anti-Islanding Test Report, PQM/SCADA Test Reports (ถ้ามี) และเอกสารอื่นตามที่ กฟภ. กำหนด พร้อมประสานให้มีการตรวจสอบหรือทดสอบร่วมกับ กฟภ. ตามขั้นตอนที่เกี่ยวข้อง โดยห้ามเริ่มเชื่อมต่อก่อนการตรวจสอบและอนุญาตตามกระบวนการที่ใช้กับโครงการ

## 6. เอกสาร O&M และการเปลี่ยนแปลงภายหลัง

**ขอบเขตการใช้:** งานส่งมอบ/O&M  
**อ้างอิงในไฟล์ต้นฉบับ:** `O ข้อ 2.10, 3; C ข้อ 2.11`

> ผู้รับจ้างต้องส่งมอบ Operation & Maintenance Manual, Single Line Diagram ล่าสุด, Protection/Control Settings, Commissioning Records, Contact List และแผนการตรวจประเมินที่เกี่ยวข้อง พร้อมข้อปฏิบัติเมื่อระบบไฟฟ้าไม่ปกติ ทั้งนี้หากมีการเพิ่มเติมหรือเปลี่ยนแปลงอุปกรณ์ การควบคุม หรือการจ่ายไฟ ต้องตรวจสอบข้อกำหนดและดำเนินการขอความเห็นชอบจาก กฟภ. ก่อนเปลี่ยนแปลงตามข้อ 2.11 ของ Connection Code

## Checklist ก่อนนำร่าง TOR ไปใช้จริง

- [ ] ตรวจชนิดโครงการ IPU / IPS / VSPP / SPP และขอบเขตการจ่ายไฟที่อนุญาต
- [ ] ตรวจขนาด Inverter AC, PV DC, PCC และแรงดัน
- [ ] ตรวจรูปแบบ Annex 7.1 และแบบที่ กฟภ. อนุมัติ
- [ ] แยกรายการที่ **บังคับ** กับ **ตัวเลือกตามเงื่อนไข** เช่น PQM/SCADA/EXL
- [ ] กำหนด FAT / SAT / Test Record / Witness / Handover ให้ตรวจรับได้จริง
- [ ] ทวนหมายเลขข้อและถ้อยคำใน Grid Code ฉบับจริงก่อนออก TOR
